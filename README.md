# goit-pycore-hw-03

Homework for topic 4 of the course "Python Programming: Foundations and Best Practices 2.0".

| File | Task |
|---|---|
| `task_1.py` | `get_days_from_today(date)` — number of days from a given date to today |
| `task_2.py` | `get_numbers_ticket(min, max, quantity)` — unique random numbers for a lottery ticket |
| `task_3.py` | `normalize_phone(phone_number)` — phone number normalization |
| `task_4.py` | `get_upcoming_birthdays(users)` — birthday congratulations for the next 7 days |

Each file runs on its own (`python task_1.py`) and prints an example of the function's work.
