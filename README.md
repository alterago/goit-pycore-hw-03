# goit-pycore-hw-03

Домашнє завдання до теми 4 курсу «Python Programming: Foundations and Best Practices 2.0».

| Файл | Завдання |
|---|---|
| `task_1.py` | `get_days_from_today(date)` — кількість днів від заданої дати до сьогодні |
| `task_2.py` | `get_numbers_ticket(min, max, quantity)` — унікальні випадкові числа для лотереї |
| `task_3.py` | `normalize_phone(phone_number)` — нормалізація телефонних номерів |
| `task_4.py` | `get_upcoming_birthdays(users)` — привітання з днем народження на 7 днів уперед |

Кожен файл запускається окремо (`python task_1.py`) і виводить приклад роботи функції.
